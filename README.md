<h1>Travel Planner</h1>

<h2>About</h2>

<p>Travel Planner is a web application designed to help users plan personalized trips based on their destination, travel dates, budget, interests, and transportation preferences.</p>

<h2>Planned Features</h2>
<ul>
  <li>Customizable trip preferences</li>
  <li>Interactive map with destination markers</li>
  <li>Route visualization between attractions</li>
  <li>Day-by-day itinerary generation</li>
  <li>Budget estimation</li>
  <li>Optional GPS location detection</li>
</ul>

<h2>Technologies</h2>
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
  <li>Leaflet</li>
  <li>OpenStreetMap</li>
</ul>
