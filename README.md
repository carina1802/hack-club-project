<h1>Travel Planner</h1>

<h2>About</h2>

<p>Travel Planner is a web application designed to help users plan personalized trips based on their destination, travel dates, budget, interests, and transportation preferences. It features an interactive map that allows users to discover nearby attractions, museums, restaurants, and cafés. Users can select their preferred destinations, build customized itineraries, and calculate routes with walking or driving options, including estimated distances and travel times, all within one intuitive platform.Additionally, the application provides live location tracking, helping users identify their position on the map and navigate their surroundings more easily. Its interactive features bring trip discovery, route planning, and itinerary management together, making travel organization more accessible, flexible, and convenient.</p>

<h2>Planned Features</h2>
<ul>
  <li>Customizable trip preferences</li>
  <li>Interactive map with destination markers</li>
  <li>Route visualization between attractions</li>
  <li>Day-by-day itinerary generation</li>
  <li>Budget estimation</li>

</ul>
